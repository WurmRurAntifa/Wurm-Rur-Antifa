# Wurm-Rur Antifa Website (Überarbeitet)

Diese Website ist eine moderne, responsive Landingpage für die Wurm-Rur Antifa mit vier Unterseiten. Sie wurde mit Bootstrap 5 überarbeitet für bessere Benutzerfreundlichkeit und Responsivität.

## Struktur

- `index.html`: Zentrale Startseite (Landingpage)
- `aktuelles.html`: Blog-System für Neuigkeiten
- `highlights.html`: Galerie mit Instagram-Posts und Reels
- `arbeitsgruppen.html`: Vorstellung der Arbeitsgruppen
- `stickersammlung.html`: Präsentation der Sticker-Kollektion
- `css/style.css`: Zusätzliche benutzerdefinierte Styles
- `js/script.js`: JavaScript für Interaktivität
- `images/`: Ordner für Bilder (fügen Sie echte Sticker-Bilder hinzu)

## Design

- **Farbschema**: Schwarz (#000), Rot (#ff0000), Weiß (#fff)
- **Framework**: Bootstrap 5 für moderne Layouts und Responsivität
- **Layout**: Übersichtlich, benutzerfreundlich, mobil-optimiert

## Verwendung

1. Starten Sie einen lokalen Server: `python -m http.server 8000`
2. Öffnen Sie `http://localhost:8000/index.html` in einem Webbrowser.

Die Navigation führt zu den verschiedenen Unterseiten.

## Anpassungen

- Fügen Sie echte Bilder in den `images/` Ordner hinzu.
- Ersetzen Sie die Platzhalter in `highlights.html` mit echten Instagram-Embeds.
- Aktualisieren Sie die Inhalte in den HTML-Dateien nach Bedarf.
- Die Website lädt Bootstrap von CDN, daher ist eine Internetverbindung erforderlich.
